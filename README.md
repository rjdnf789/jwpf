# 웹 개발자 안지원 포트폴리오

Java·Spring 기반의 웹 시스템을 화면 구현부터 DB 설계, 배포까지 경험한 5년 차 웹 개발자 안지원의 포트폴리오입니다.

- 사이트: https://rjdnf789.github.io/jwpf/

## 사용 기술

HTML · CSS · JavaScript (별도 프레임워크·빌드 도구 없이 정적 페이지로 제작)

## 구성

```
index.html          # 페이지
resources/
  css/              # 스타일
  js/               # 동작(스크롤 효과, 모달 등)
  images/           # 프로젝트 이미지
```
